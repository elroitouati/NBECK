# DNBA

משחק ניחוש יומי בסגנון וורדל על שחקני ה-NBA של העונה הנוכחית. אפליקציית אנדרואיד (Kotlin + Jetpack Compose, Material 3, minSdk 26), בלי שרת ובלי התחברות.

## מבנה הקוד

| תיקייה | מה יש שם |
|---|---|
| `app/src/main/java/com/nbeck/app/game` | מנוע המשחק: חישוב צבעים וחצים (`Engine.kt`), השלמה אוטומטית סלחנית (`Search.kt`), בחירת השחקן היומי (`Daily.kt`), טבלת הדיביז'נים החכמה (`DivisionBoard.kt`), סטטיסטיקות והישגים (`Progress.kt`) |
| `.../data` | טעינת שחקנים מ-ESPN (`EspnSource.kt`), מטמון + גיבוי (`PlayerRepository.kt`), רענון יומי (`RefreshWorker.kt`), DataStore (`Prefs.kt`), 30 הקבוצות (`Teams.kt`) |
| `.../ui` | מסכים, רכיבים, ערכת עיצוב (`theme/Theme.kt` — כל הטוקנים), טקסטים בעברית ובאנגלית (`Strings.kt`) |
| `app/src/main/assets/players.json` | קובץ הגיבוי המובנה (518 שחקנים) |
| `app/src/main/assets/rings.json` | כל השחקנים שזכו באליפות מאז 2004, לפי שנה |
| `tools/fetch_players.py` | הסקריפט שבונה את שני הקבצים |
| `tools/gen_sounds.py` | הסקריפט שמייצר את הצלילים |

## נתוני שחקנים

- **מקור:** ה-API הציבורי של ESPN (חינמי, בלי מפתח): סגלים, טבלאות עומק, ממוצעי עונה ותמונות ראש. מתועד בראש `EspnSource.kt`.
- **עמדות:** G, F או C בלבד (PG/SG → G, SF/PF → F).
- **שנת דראפט:** מ-ESPN; שחקן שלא נבחר מוצג כ-UND. נשלפת רק לשחקנים חדשים, כי היא לא משתנה.
- **מספר גופייה:** לפי המשחק האחרון של כל קבוצה (מה שהשחקן לבש בפועל), כי הפרופיל של ESPN לפעמים לא מעודכן (למשל ג'מאל שד: 23 בפרופיל, 1 במשחק).
- **מדינה:** מקום הלידה לפי ESPN, או המדינה שהשחקן מייצג כשזה שונה.
- **תיקונים ידניים:** `assets/corrections.json` (נבנה מ-`CORRECTIONS` ו-`WIKIDATA_FIXES` ב-`tools/fetch_players.py`) — מדינות, תאריכי לידה ומספרים שנבדקו מול Wikidata. האפליקציה מחילה אותם אחרי כל רענון, כך ש-ESPN לא דורס אותם.
- **רענון:** בכל פתיחה של האפליקציה (לא יותר מפעם ב-10 דקות), וגם פעם ביום ברקע.
- **טבעת:** נגזרת מכל משחקי הגמר מאז 2004 — כל שחקן שמופיע בבוקס-סקור של האלופה (שיחק או ישב על הספסל). **אחרי כל גמר יש להריץ `python3 tools/fetch_players.py` ולבנות גרסה חדשה** כדי להוסיף את האלופים החדשים.
- **מטמון:** ההורדה האחרונה נשמרת במכשיר, כך שהמשחק עובד גם בלי רשת. תמונות נשמרות במטמון דיסק.
- **גיבוי:** אם אין רשת בפתיחה הראשונה נטען `assets/players.json`. לעדכון שלו לפני בנייה: `python3 tools/fetch_players.py`.
- **שחקן יומי:** נבחר בגיבוב rendezvous לפי התאריך, כך שכל החברים מקבלים אותו שחקן גם אם המטמון של מישהו ישן ביום.

## מצבים

- **יומי** — אותו שחקן לכל החברים. **אתגרים קודמים**: אפשר לשחק את האתגר היומי של כל אחד מ-30 הימים האחרונים. משחק כזה נספר בסטטיסטיקות היומיות (משחקים, ניצחונות, התפלגות) אבל לא משפיע על הרצף, שמתייחס רק למשחק של היום.
- **חופשי** — שחקן אקראי, בלי הגבלה.

## קטגוריות

קבוצה · דיביז'ן · עמדה · גיל · מספר · מדינה · דראפט · טבעת. דראפט מתנהג כמו גיל (מדויק = ירוק, עד 3 שנים = צהוב, חץ למעלה/למטה; UND תואם רק UND). טבעת: ✓ זכה / ✗ לא זכה — ירוק אם זהה לשחקן הסודי, אפור אם לא.

## בניית APK חתום (release)

צריך: JDK 17+ ו-Android SDK (או Android Studio).

1. **יצירת מפתח חתימה — פעם אחת בלבד.** שמור את הקובץ והסיסמה במקום בטוח: בלי אותו מפתח בדיוק, החברים לא יוכלו להתקין עדכונים על הגרסה הקיימת.
   ```bash
   keytool -genkeypair -v -keystore nbeck-release.jks -alias nbeck \
     -keyalg RSA -keysize 2048 -validity 10000
   ```
2. **יצירת `keystore.properties`** בתיקייה הראשית (הקובץ לא נכנס ל-git):
   ```properties
   storeFile=nbeck-release.jks
   storePassword=הסיסמה
   keyAlias=nbeck
   keyPassword=הסיסמה
   ```
3. **בנייה:**
   ```bash
   ./gradlew :app:assembleRelease
   ```
   הקובץ: `app/build/outputs/apk/release/app-release.apk`

**פרסום גרסה (כדי שהחברים יקבלו התראה):** אחרי הבנייה הרץ `python3 tools/publish_release.py` ועשה commit + push ל-`release/`. האפליקציה בודקת את `release/latest.json` במאגר בכל פתיחה ופעם בכמה שעות ברקע; אם יש בו `versionCode` גבוה יותר, היא שולחת התראה שלחיצה עליה מורידה את `release/DNBA.apk`. (גרסאות לפני 1.7.0 לא יודעות לבדוק — צריך להתקין את 1.7.0 ידנית פעם אחת.)

לגרסה חדשה: העלה את `versionCode` (ו-`versionName`) ב-`app/build.gradle.kts`, **הוסף רשומה בראש `data/Changelog.kt`** (עם אותו `versionCode`) — היא מה שמוצג בחלונית "מה חדש" אחרי העדכון ובהיסטוריית הגרסאות בהגדרות — ובנה שוב עם אותו מפתח.

## התקנה אצל החברים (שליחה בוואטסאפ)

1. שלח את `app-release.apk` בוואטסאפ **כמסמך** (📎 ← מסמך), לא כתמונה/מדיה.
2. אצל החבר: לוחצים על הקובץ בצ'אט ← "פתח".
3. בפעם הראשונה אנדרואיד יציג "מטעמי אבטחה, לא ניתן להתקין אפליקציות לא ידועות ממקור זה". לוחצים **הגדרות** ← מפעילים **"אפשר ממקור זה"** (התקנה ממקורות לא ידועים) עבור וואטסאפ ← חוזרים אחורה.
4. לוחצים **התקן**. אם Play Protect מציג אזהרה ("אפליקציה לא מוכרת") ← **פרטים נוספים** ← **התקן בכל זאת**.
5. אחרי ההתקנה אפשר לכבות שוב את "אפשר ממקור זה" בהגדרות.

עדכון: שולחים APK חדש (עם `versionCode` גבוה יותר וחתום באותו מפתח) ומתקינים מעליו — הסטטיסטיקות וההישגים נשמרים.
